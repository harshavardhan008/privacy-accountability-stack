Four quiet leaks

  • Wide tool scope. The agent can read far more than the task needs.
  • Context carry-over. Data from one request shows up in the next.
  • Summaries become new copies. A ticket or note holds personal data nobody tracked.
  • Lost purpose in handoffs. The next agent does not know why it may touch the data.

Honest limits

The evaluation uses 200 synthetic customers and constructed scenarios. It shows the mechanisms work as designed. It does not measure how common these failures are in real deployments, which is what the checkup is meant to start collecting, anonymously. The reference gateway is for study and testing, not a production security boundary.
